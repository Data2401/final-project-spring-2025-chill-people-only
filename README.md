🔋 **Charging Forward: A Data-Driven Look at Electric Vehicles Population (in the State of Washington)**
================
📌 ***Project Overview***
===
This R project analyzes electric vehicle (EV) registration trends in Washington State using data from the Washington State Department of Licensing. Through statistical analysis and visualization, 
we examine EV distribution, efficiency trends, manufacturer dominance, and geographic adoption patterns to gain insights into the evolving EV landscape.


📂 ***Files***
===
📥 The original dataset can be downloaded at ***<u>https://data.wa.gov/api/views/f6w7-q2d2/rows.csv?accessType=DOWNLOAD)</u>***

🗂  Electric_Vehicle_Population_Data_1.csv - Filtered dataset for the Project purposes.

💻Electric_Vehicle_Project.Rmd - Main Markdown file including code and graphs.

🌐 Electric_Vehicle_Project.html - HTML Project file.

🔍***Analysis Components***
===
📊 **EV Registrations Over Time** – How adoption has changed across model years.

🗺️ **Geographic Distribution** – EV penetration by county and city.

⚡ **EV Efficiency & Range Trends** – Examining range progression over model years.

🚗 **Manufacturer Dominance** – Identifying leading EV brands across different counties.

🔎 **EV Type Breakdown** – Comparing Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
